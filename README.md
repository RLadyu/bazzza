# bazzza

## Готовый шаблон Excel для опросника отделения

Я добавил файл `hospital_survey_app.xml` — это Excel 2003 XML Workbook, который открывается в Microsoft Excel.

### Что внутри
- Лист **Инструкция** с коротким сценарием работы.
- Лист **Пациенты** для регистрации пациентов.
- Лист **Опрос** для внесения ответов по шкале 1–5.
- Лист **Свод** с автоматическим подсчетом количества анкет и среднего балла.

### Как использовать
1. Откройте `hospital_survey_app.xml` в Excel.
2. Сохраните как `.xlsx` (Файл → Сохранить как).
3. Размножьте строки на листах **Пациенты** и **Опрос** под нужное число пациентов.
4. Вносите данные — сводные метрики пересчитаются автоматически.
